# ACEIT Sports Club Website & Server

Complete multi-sport web application for ACEIT Jaipur with 6 sports clubs, player profiles, photo gallery, tournament registrations, live scoring, and admin dashboard.

## 📁 Project Files

- `aceit-spikers-1.html` — Main Web Application Frontend
- `server.js` — Node.js Express Backend API Server
- `package.json` — Server Dependencies & Scripts
- `vercel.json` — Vercel Serverless Deployment Config
- `data/database.json` — Central Server Database (auto-generated)

---

## 🚀 Running Locally

1. **Install Dependencies** (Make sure Node.js is installed on your computer):
   ```bash
   npm install
   ```

2. **Start the Server**:
   ```bash
   npm start
   ```

3. **Open in Browser**:
   Navigate to [http://localhost:3000](http://localhost:3000)

---

## 🌐 Deploying to Vercel (1-Click Free Hosting)

1. Push your folder/repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "ACEIT Sports Club initial commit"
   git push
   ```

2. Go to [Vercel.com](https://vercel.com) -> **Add New Project**.
3. Import your GitHub repository.
4. Click **Deploy**! 

*Vercel will automatically read `vercel.json` and deploy both your frontend and backend API live for free!*
